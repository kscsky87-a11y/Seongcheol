API & 데이터 정합성 검증 프로토콜

SQL + POSTMAN + CONTRACT-FIRST
STEP 01 · DESIGN

Contract-First 명세

  • Endpoint · Request/Response Schema 표준 정의
  • HTTP 상태 코드 및 Error Code 사전 합의
  • 기획–백엔드–프론트엔드 필드 단위 100% 일치
STEP 02 · QUERY

SQL 역추적 검증

  • DB 원천 테이블 조인(Join) 구조 직접 매핑
  • Null 허용 여부 및 데이터 누락·중복 사전 차단
  • 실데이터 기반 엣지 케이스 쿼리 검증
STEP 03 · VERIFY

Postman 페이로드 테스트

  • 배포 전 API 응답 페이로드 및 Edge Case 사전 검증
  • 프론트엔드 렌더링 SLA 응답속도 충족 확인
  • 장애 원인(DB vs API vs UI) 분리 후 Jira 즉시 트래킹
